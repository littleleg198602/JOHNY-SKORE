# Read-only NHTSA scope-review UI API

Call `read_nhtsa_scope_reviews(existing_store, as_of=aware_datetime, limit=8)`
from `market_checker_app.services.nhtsa_negative_review_service`. Limits are
integers from 1 through 100. The caller supplies an existing `ScoutStore` handle;
the function reads only `store.db_path`. It does not construct a store, review
service or HTTP client, create tables, reserve quota, or change source records.
The existing `NhtsaNegativeReviewService.report` method delegates to this API.

SQLite opens with `mode=ro` and `PRAGMA query_only=ON`, within one read snapshot.
The physical `scout_nhtsa_scope_reviews.known_at` column supplies the inclusive
cutoff. Reviews remain unchanged and sort by descending physical knowledge time,
then review ID. Counts describe the returned review window and do not measure
issuer or canonical-universe coverage.

`NO_RECORDED_REVIEWS` explicitly identifies an absent database, absent review
table, or no cases known at the requested cutoff. A corrupt database or malformed
review JSON returns `REVIEW_READ_ERROR`. Neither status establishes a negative
source result. `RECORDED_REVIEWS` means only that recorded cases were returned.

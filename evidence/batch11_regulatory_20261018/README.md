# Offline EPA FRS program-interest scope

`review_epa_frs_program_scope(request, captures, *, reviewed_at=None)` reviews one exact facility and bounded program/interest source fields from pinned whole JSON. It performs no file, network, collector, search, database, quota or registry I/O. The integration kind is `EPA_FRS_PROGRAM_SCOPE` and the actual plan is `actual_review_plan.json`.

The facility pointer must select its exact twelve-digit RegistryId/RegistryID and literal facility name. A program pointer must be a direct ProgramFacilities child of that facility and match both its acronym and system ID. An interest pointer stays in that program object or one direct child-array row. Source dates and roles never fall through to parent, sibling, other-program or other-facility rows. Each returned literal carries its source JSON pointer, canonical value hash and original-body hash. Program names remain their own literals; an absent name does not inherit a facility/operator/parent name.

The supported source layout is the existing narrow Results/Message/QueryRows/Facilities/ProgramFacilities contract. Synthetic role/date fields in the tests are contract examples, not publisher schema documentation. Caller-selected field semantics are explicitly unverified. A parseable source date is a lexical observation, not proof of an event, ownership interval, operating permission, current registration or continuous company exposure. Missing, null, empty, invalid and unrecognized dates stay separate. All reports remain PARTIAL, with legal ownership, issuer identity, absence, liability, live acceptance, adoption and scoring flags false.

The actual retained DOW case still has no whole EPA response. Its original metadata records hash `df9d3731…`, unknown byte length and no archive path; `evidence/epa_echo_live_20261002.json` is a historical summary. This new reviewer rejects that missing original and records no facility/program/date facts. The actual plan has no invented program selectors. The summary is never exported as a replacement response, and no source fetch was attempted. Independent original program-interest records, publisher field semantics, dated legal ownership and issuer continuity remain missing.

Physical `review_started_at` precedes interpretation; `known_at`/`review_completed_at` follow all derived facts and supporting-clock checks. `reviewed_at`/`source_read_cutoff` limit source reads and never represent output availability. Future cutoffs, physical rollback and completion before supporting clocks reject the report. A historical source date never backdates newly derived knowledge.
